# Sheets2Spotify
Using Google Sheets API, Spotify API, and Spotipy, I built a program that automatically adds songs from a specific Google Sheet.
<br>You have to create your own API key for Google Sheets and Spotify. 
<br>Make sure you download the OAuth 2.0 Client ID key JSON for your Google API and set environment variables for Spotify API.
<br>Set the SPREADSHEET_ID, PLAYLIST_ID, USERNAME variables to your own and run the code, it should take care of the rest
