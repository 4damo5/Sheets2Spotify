# Sheets2Spotify
Using Google Sheets API, Spotify API, and Spotipy, I built a program that automatically adds songs from a specific Google Sheet.
<br>You have to create your own API key for Google Sheets and Spotify.
<br>Share the Google Sheet with the Google Sheets API email and switch the username in the s2s.py file.
<br>Also change the spreadsheet ID and playlist ID to match your own.
